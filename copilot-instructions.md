* whenever you want to run python code, check if there is a `venv` configured, usually in `.venv` and make sure you use it
* for any files you edit, run `black` to correct the formatting, if black is available.
* be economic, avoid unnecessary computations and token usage.
* strive for clarity and conciseness in your code and comments. Remove functions, variables, and comments that are not needed.
* Always add comments to explain non-trivial parts of the code and add docstrings to all functions and classes.
* favour object-oriented design where appropriate.
* if you add new dependencies, add them to `requirements.txt` without version specifiers, unless a very specific version is required.
